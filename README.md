# Cotizador Swiss Medical · Grupo Zeroka

Primera versión visual del portal comercial. Incluye acceso, formulario, catálogo de 15 planes, selección y cotización de cuatro páginas lista para impresión/PDF.

## Estado

- Diseño desktop y mobile implementado.
- Imágenes locales para una carga estable.
- Valores, aportes y campañas deliberadamente pendientes del tarifario oficial.
- Beneficios por plan pendientes de la revisión final de las cartillas.

## Vista local

Abrir `login.html`. En modo archivo el acceso conduce al portal sin validar credenciales. En producción, Netlify utiliza `AUTH_USER`, `AUTH_PASSWORD` y `SESSION_SECRET`.
